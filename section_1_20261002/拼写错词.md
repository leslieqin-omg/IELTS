# IELTS 写作高频错题与拼写黑名单

### 1. 基础拼写与手误（重点突破）

| 错误原形 | 正确拼写 | 错因分析 | 记忆技巧 |
| :--- | :--- | :--- | :--- |
| **Seccondly** | **Secondly** | 多写了 c | second + ly，只有一个 c |
| **creativit** | **creativity** | 漏了词尾 y | create -> creative -> creativity |
| **peopel** | **people** | 元音位置颠倒 | -ple 结尾，不要写成 -pel |
| **anserw** | **answer** | 辅音元音颠倒 | ans-wer |
| **opionin** | **opinion** | 元音位置颠倒 | o-pi-nion |
| **depands** | **depends** | 字母 e 写成 a | de-pend |
| **intellactaul** | **intellectual** | 拼写混淆 | in-tel-lec-tual（双 l） |
| **laboer** | **labor / labour** | 词尾混淆 | 美式 labor，英式 labour |
| **pronmpts** | **prompts** | 多加了 n | prompt |
| **wright** | **write** | 同音词混淆 | write (写) vs wright / right |
| **human bings'** | **human beings'** | 漏了字母 e | being (存在/人类) |
| **instand of** | **instead of** | 字母拼写颠倒 | in-stead of |
| **replacd** | **replaced** | 漏了 e | replace -> replaced |

### 2. 语法与句式规范

| 原句 / 错误用法 | 纠正方案 | 语法规则 |
| :--- | :--- | :--- |
| they would replaced by AI | they would **be** replaced by AI | 被动语态不可遗漏 be 动词 |
| Due to these tasks demands... | **Because** these tasks demand... / **Due to** the demand of... | Due to 后面接名词/短语，不能直接接完整主谓从句 |
| rarely to replaced | **are unlikely to be replaced** | 形容词搭配与被动语态正确形式 |
| handle this works | handle **this work** / handle **these tasks** | work 作“工作”讲时不可数 |
