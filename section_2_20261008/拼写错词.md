# IELTS Section 2 写作高频错词与语法避坑清单

本篇是你在 Section 2 大作文中出现的**致命拼写错词**与**高频语法漏洞**汇总。请重点记忆每个词的正确形式和构词口诀！

---

## 一、高频手误与易错词黑名单（本次实测 17 处）

| 错误原形 | 正确拼写 | 错因分析 | 记忆技巧与口诀 |
| :--- | :--- | :--- | :--- |
| **peopel** (出现4次) | **people** | 元音与辅音字母位置颠倒 | 牢记是 `-ple` 结尾（如 apple, purple, people），绝不是 `-pel`！ |
| **mouney** (出现3次) | **money** | 莫名多加了字母 u | mon-ey，绝对没有 u！ |
| **univerrsity / univerty** | **university** | 字母漏写或多写 | u-ni-ver-si-ty（一共 10 个字母，单 r 单 s）。 |
| **urben** | **urban** | 元音 a 误写成 e | ur-ban（城市），反义词为 rural（乡村）。 |
| **succesful** | **successful** | 漏写双写 s | suc-ces-s-ful（双 c，双 s，单 l）。 |
| **totolly** | **totally** | 元音字母混淆 | total + ly -> to-tal-ly（中间是 a 不是 o）。 |
| **attandency** | **attendance / enrollment** | 错造词形且拼错 | attend (v.) -> attendance (n. 出席/就读)；enrollment (注册入学)。 |
| **obligant** | **obligatory / compulsory** | 错造形容词 | obligate (v.) -> obligatory (adj. 义务的/必须的)；或用 compulsory。 |
| **decrase** | **decrease** | 漏写字母 a | de-crease（减少/降低），反义词 increase。 |
| **accormondation** | **accommodation** | 极其经典的双写大坑 | **双 c 双 m**！一间房两个床(cc)，两个客(mm)。 |
| **bearly** | **barely** | 误写成熊(bear)的副词形式 | bare + ly -> barely（几乎不，仅仅）。 |
| **opptunity** | **opportunity** | 漏写字母 or | op-por-tu-ni-ty（双 p，单 t）。 |
| **staller tanlent** | **stellar talent** | 元音字母颠倒及手误 | stellar (顶尖的/恒星般的)；ta-lent (才华)。 |
| **finatial** | **financial** | 字母 c 错写成 t | finance (财政) -> financial (金融的/财务的)。 |
| **schoolarship** | **scholarship** | 误受 school 影响多加 o | scho-lar-ship（学者是 scholar，只有一个 o）。 |
| **feculty'** | **faculty's** | 词首元音误写为 e | fa-cul-ty（大学教职员工/系所）。 |
| **contrubution** | **contribution** | 元音 i 错写成 u | con-tri-bu-tion（贡献/建设投入）。 |
| **ellevating** | **elevating** | 误以为是双写 l | e-le-vate（单 l，抬升/提升地位）。 |

## 二、语法与结构核心漏洞剖析

1. **情态动词绝对不能连用**：
   - 错误：`may can ask them to`
   - 正确：`could ask them to` 或 `may be able to ask them to`。
2. **介词后动词形式必须是动名词 (-ing)**：
   - 错误：`donateing some mouney in 基金`（拼写且搭配错误）
   - 正确：`contributing money to an endowment fund`。
3. **主谓一致性原则**：
   - 错误：`those who has a stellar talent`
   - 正确：`those who have stellar talent`（those 为复数先行词，关系代词 who 指代复数，谓语动词必须用 have）。
4. **大作文结构底线：绝不能缺失结尾段（Conclusion）**：
   - 雅思官方评分标准明确要求：如果没有结论段，无论正文多好，TR（任务回应）上限只能给到 5.5。下次必须留出 3 分钟写下两句总结！
